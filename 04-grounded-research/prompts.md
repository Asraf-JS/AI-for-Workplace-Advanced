# 04 - Grounded Research and Source-Based Answers: Prompts

Questions for the policy notebook. Add `procurement-policy-v3.0.pdf` and `approved-vendor-list.pdf` from [sample-files.zip](./sample-files.zip) as sources first. Hover over a grey box and click the copy icon in its top-right corner.

> **Session guide:** every part runs in the **same notebook** (or Project).

---

## Part 1: Check the sources

**Session:** new notebook | **Grounding:** the two PDFs as sources

```
In three bullets, what do these sources cover? Name each document and its version or date.
```

---

## Part 2: Five policy questions

**Session:** same notebook | **Grounding:** sources

```
Answer only from the sources. For each answer, give the clause number and quote the exact sentence it comes from. What is the most we can pay in advance before the Finance Director has to approve it?
```

```
How long must a supplier's quotation be valid for?
```

```
Who has to approve a purchase of RM80,000 including tax?
```

```
Does a quotation have to show the supplier's SST registration number?
```

```
What happens if one department places several small orders with the same supplier in the same month?
```

If an answer drops the quote:

```
Quote the exact sentence for that too.
```

---

## Part 3: A question the sources don't answer

**Session:** same notebook | **Grounding:** sources

```
Answer only from the sources. What is our policy on buying from suppliers outside Malaysia?
```

If it gives you rules anyway:

```
Quote the clause that says that.
```
