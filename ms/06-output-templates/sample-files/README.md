# Template Modul 06

Template Word dan PowerPoint untuk syarikat rekaan Sinar Maju Sdn Bhd, digunakan dalam [Modul 06](../).

> **Muat turun:** **[sample-files.zip](../../../06-output-templates/sample-files.zip)** (ketiga-tiganya sekali gus), kemudian klik kanan fail itu dan pilih **Extract All** sebelum anda mula.

| Fail | Kandungan |
|---|---|
| `sinar-maju-deck.pptx` | Template persembahan syarikat, dibina dengan betul |
| `sinar-maju-deck-bad.pptx` | Slaid yang sama, dibina dengan buruk. Anda akan membandingkan kedua-duanya dalam lab |
| `sinar-maju-memo.docx` | Template memo kelulusan |

Ketiga-tiganya ialah bahan latihan rekaan.
